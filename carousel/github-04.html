The #1 confusion
Git ≠ GitHub
People use them interchangeably. They're not the same thing.
The tool
Git
Software on your computer that tracks every change you make.
  • Works offline
  • Created by Linus Torvalds
  • "Version control"
The website
GitHub
An online home for your Git projects — plus collaboration.
  • Lives in the cloud
  • Owned by Microsoft
  • Share & work together
