Step 1

Make your first .md file

You don't install Markdown — it's just text. You only need somewhere to type it.

The 30-second version:

1. Open any text editor (even Notepad / TextEdit).

2. Type a line:  # My notes 

3. Save the file as  notes.md  (not .txt).

That .md ending tells other apps "read this as Markdown." On its own it's still plain text — the magic shows when an app previews it (next step).

Step 2 · the setup

Install a proper editor

To see your Markdown render live, use one of these free apps. Pick one:

✍️ Obsidian — best for notes

Download at obsidian.md. Type Markdown, see it formatted instantly. Free.

💻 VS Code — best for projects

Get it at code.visualstudio.com. Open any .md and press Ctrl/Cmd + Shift + V for a live preview.

🌐 Nothing to install — quickest

Paste Markdown straight into GitHub, Notion, or Claude — they all render it automatically.
