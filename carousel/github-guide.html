Step 1

Create your account

Head to github.com and click Sign up. Two minutes, free forever.

1
Enter your email, a password, and a username.
2
Verify your email.
3
You're in — that's your profile.

Your username matters. It becomes your public URL: github.com/your-name. Keep it clean and on-brand — it's the link you'll share on your résumé and socials.

Step 2

Make your first repository

A repo is your project folder. Let's create one.

1
Click the + (top-right) → New repository.
2
Name it my-first-project.
3
Choose Public (anyone can see) or Private (just you).
4
Tick Add a README file.
5
Click Create repository.

🎉 You now have a live repo at github.com/you/my-first-project. The README.md is the front page everyone sees first.

Step 3

Your first commit

A commit = a saved snapshot. You can do this right in the browser — no install needed.

1
Open your repo and click README.md.
2
Click the pencil ✏️ to edit.
3
Type something: # My First Project
4
Scroll down → write a short message → Commit changes.
Commit message
Add project title to README

✓ committed e4c5a90  — your first snapshot, saved forever

Good messages describe what changed, e.g. "Add contact form" — your future self will thank you.

Step 4 · level up

Work from your computer

Editing in the browser is fine to start. To build for real, use Git locally.

1. Install Git from git-scm.com.

2. Copy your repo down (clone it):

git clone https://github.com/you/my-first-project.git

3. The everyday loop — make changes, then:

git add .                        # stage your changes
git commit -m "what I changed"   # save a snapshot
git push                         # send it to GitHub

That's 90% of daily Git: add → commit → push. Everything else you'll learn as you go.
