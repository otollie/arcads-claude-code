The idea

What a skill actually is

A skill is a folder that teaches Claude a job. At its core is one file — SKILL.md — written mostly in plain English. You can also bundle scripts, templates, fonts, or data the task needs.

The magic is progressive disclosure: Claude only sees each skill's name and description until your request actually needs it — then it loads the full instructions and files. That means you can keep dozens of skills without slowing Claude down.

Skill vs. a saved prompt

A saved prompt is just text you paste. A skill is reusable expertise Claude loads on its own — and it can carry real tools (code, fonts, API flows), not just words.

"Explain it once. Use it forever."

Do it now

Your first skill in 5 minutes

Create a folder, add one file, and paste this in. The description line is the most important part — it's how Claude decides when to use the skill.

my-skill/SKILL.md
---
name: linkedin-rewriter
description: Rewrites rough notes into a punchy LinkedIn
  post in my voice. Use when I paste notes and ask for
  a LinkedIn post.
---

# What this does
Turn my messy notes into one scroll-stopping post.

## Rules
- Hook in the first line. No "I'm excited to announce".
- Short lines. One idea per line.
- End with a question to drive comments.

That's a working skill. Drop it where Claude can see it (next page), then just say: "here are my notes — make a LinkedIn post."

3 skills to use today

Copy the description into a new SKILL.md, tweak the rules to your brand, done.

carousel-maker
Description: Builds an on-brand Instagram carousel (cover + slides) from a topic. Use when I ask for a carousel or slides.
2
thumbnail-maker
Description: Generates high-CTR YouTube thumbnail concepts and copy. Use when I mention a thumbnail or video title.
3
content-repurposer
Description: Turns one long video or post into 5 short-form hooks across platforms. Use when I paste a transcript or ask to repurpose.

Tip: keep each skill narrow. One job, one folder. Narrow skills trigger more reliably than a giant do-everything one.

Ship it

Where to install

Claude Code

Put the folder in one of these:

.claude/skills/my-skill/SKILL.md   # this project
~/.claude/skills/my-skill/SKILL.md  # every project

Claude detects it automatically — no restart, no config.

claude.ai

Add it under Settings → Capabilities → Skills. Anthropic also ships official skills (canvas-design, pdf, pptx, xlsx) at github.com/anthropics/skills — a great place to learn the format.
